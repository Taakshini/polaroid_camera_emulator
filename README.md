# Polaroid Camera Emulator 📸

A fun web application that simulates a Polaroid camera with real-time filters and instant photo capture effect.

## Features
- Real-time camera feed
- Polaroid-style photo frame
- Multiple filter options
- Download captured photos

## Tech Stack
- HTML5
- CSS3
- JavaScript
- MediaDevices API

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
3. Allow camera permission
